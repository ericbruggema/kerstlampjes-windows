一个只含彩灯的小程序：一串灯沿屏幕边缘（任务栏上方）显示，始终可见，并且可以直接点击穿透。

**快速上手**

1. 下载 [Kerstlampjes-Windows.exe](https://github.com/ericbruggema/kerstlampjes-windows/releases/latest/download/Kerstlampjes-Windows.exe) 并双击运行。无需安装；Windows 10 或 11 即可。
2. 在右下角时钟旁找到灯泡图标（有时在 ^ 箭头后面）。
3. **左键单击**图标开关彩灯，**右键单击**打开菜单：

| 菜单项 | 作用 |
|---|---|
| 开灯 | 开启或关闭彩灯 |
| 设置… | 效果、颜色、装饰等 |
| 放烟花 · 让冰柱掉落 · 扫掉积雪 | 装饰的快捷操作 |
| 随 Windows 启动 | 开机时自动启动程序 |
| 检查更新 | 在 GitHub 上检查是否有新版本 |
| 关于圣诞彩灯… | 说明、版本和许可证 |
| 退出 | 关闭程序 |


- **下载：** [Kerstlampjes-Windows.exe](https://github.com/ericbruggema/kerstlampjes-windows/releases/latest/download/Kerstlampjes-Windows.exe)（100 kB，[发布页](https://github.com/ericbruggema/kerstlampjes-windows/releases/latest)）。无需安装：双击后图标出现在系统托盘（右下角时钟旁）。
- **开/关：** 左键单击图标。**右键**打开菜单：设置、随 Windows 启动、检查更新、关于和退出。
- **设置：** 效果（常亮、闪烁、交替、跑马灯、彩色波浪）、颜色、速度、大小、间距、圆角、离边缘距离、下垂、不透明度；可选所有屏幕或仅主屏幕。
- **装饰：** 与 Android 版相同（小火车、雪、烟花、冰柱、花环、雪橇、企鹅、滚动字幕），可在设置中分别开启。点击冰柱、流星、火车或企鹅它们会有反应；你的点击仍会穿透到下面的窗口。
- **烟花表演：** 可选随机烟花或某一类：火箭、喷泉、礼花弹、罗马烟花筒、旋转烟花，或编排好的大型表演（约 32 秒，然后暂停）。烟花会在底部边缘的随机位置升空，也可以从菜单手动点燃。
- **雪：** 默认落在两侧，也可以让雪花飘满整个屏幕。只有开启花环后才能选择“花环上的彩球”。
- **清除积雪：** 把鼠标划过积雪、左右晃动鼠标，或在菜单中选择*扫掉积雪*。
- **仅在桌面显示：** 可选择只在看到桌面时显示彩灯，不覆盖程序。
- **自动隐藏：** 全屏应用（游戏、视频、演示）时隐藏。
- **随音乐：** 通过麦克风对声音做出反应的效果。只有选择该效果时才会打开麦克风；不会存储或发送任何内容，只测量音量。
- **隐私：** 除非你选择“检查更新”，否则不联网。设置保存在 `%APPDATA%\Kerstlampjes`。
- **语言：** 跟随 Windows 语言（Nederlands、English、Deutsch、Français、Español、中文）。
- **Windows SmartScreen：** 文件没有数字签名；出现警告时选择*更多信息* → *仍要运行*。
- **构建：** `dotnet build -c Release`（.NET Framework 4.8，Windows 10/11 自带）。
