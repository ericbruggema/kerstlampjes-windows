Une petite appli avec seulement les lumières : une guirlande le long du bord de votre écran (au-dessus de la barre des tâches), toujours visible, et vous pouvez cliquer à travers.

**Pour commencer**

1. Télécharge [Kerstlampjes-Windows.exe](https://github.com/ericbruggema/kerstlampjes-windows/releases/latest/download/Kerstlampjes-Windows.exe) et double-clique dessus. Rien à installer ; Windows 10 ou 11 suffit.
2. Cherche l'icône d'ampoule en bas à droite près de l'horloge (parfois derrière la flèche ^).
3. **Clic gauche** sur l'icône pour allumer ou éteindre les lumières. **Clic droit** ouvre le menu :

| Élément du menu | Ce qu'il fait |
|---|---|
| Lumières allumées | Allume ou éteint les lumières |
| Paramètres… | Effet, couleurs, décorations et plus |
| Lancer un feu d'artifice · Faire tomber les glaçons · Balayer la neige | Actions rapides pour les décorations |
| Démarrer avec Windows | Lance le programme automatiquement au démarrage |
| Rechercher des mises à jour | Vérifie sur GitHub s'il existe une version plus récente |
| À propos de Lumières de Noël… | Explication, version et licence |
| Quitter | Arrête le programme |


- **Téléchargement :** [Kerstlampjes-Windows.exe](https://github.com/ericbruggema/kerstlampjes-windows/releases/latest/download/Kerstlampjes-Windows.exe) (100 ko, [release](https://github.com/ericbruggema/kerstlampjes-windows/releases/latest)). Rien à installer : double-cliquez et l'icône apparaît dans la zone de notification, en bas à droite près de l'horloge.
- **Marche/arrêt :** clic gauche sur l'icône. **Clic droit** ouvre le menu : paramètres, démarrer avec Windows, rechercher des mises à jour, à propos et quitter.
- **Paramètres :** effet (fixe, scintillement, alterné, chenillard, vague de couleurs), couleurs, vitesse, taille, espacement, arrondi des coins, distance du bord, affaissement, opacité. Aussi tous les écrans ou seulement l'écran principal.
- **Décorations :** les mêmes que sur Android (petit train, neige, feux d'artifice, glaçons, guirlande, traîneau, pingouins, bandeau lumineux), à activer séparément dans les paramètres. Clique sur les glaçons, les étoiles filantes, le train ou les pingouins et ils réagissent ; ton clic passe quand même à la fenêtre en dessous.
- **Spectacle pyrotechnique :** choisis des feux aléatoires ou un type : fusées, fontaines, mortiers, chandelles romaines, soleils ou un grand spectacle chorégraphié (environ 32 secondes, puis une pause). Il part à des endroits aléatoires le long du bord du bas ; il part d'un clic sur la **caisse de feux d'artifice** (en bas à droite) ou depuis le menu ; le lancement automatique est une option à part.
- **Neige :** tombe par défaut sur les côtés ; tu peux aussi la faire tomber sur tout l'écran. L'option boules sur la guirlande n'est disponible que si la guirlande est activée.
- **Enlever la neige :** passe la souris dans la neige, secoue-la de gauche à droite, ou choisis *Balayer la neige* dans le menu.
- **Seulement sur le bureau :** une option pour n'afficher les lumières que lorsque tu vois le bureau, pas au-dessus des programmes.
- **Se masque** pendant les applis plein écran (jeux, films, présentations).
- **Au rythme de la musique :** un effet où les lumières dansent sur le son. La source par défaut est le **son de l'ordinateur** (YouTube, Spotify, jeux) : rien n'est enregistré, seul l'indicateur de volume de Windows est lu. Sinon, la source **microphone** : le microphone n'est ouvert que si tu la choisis ; rien n'est enregistré ni envoyé, seul le volume est mesuré.
- **Confidentialité :** rien ne passe par internet, sauf si vous choisissez « Rechercher des mises à jour ». Les paramètres sont dans `%APPDATA%\Kerstlampjes`.
- **Langues :** suit la langue de Windows (Nederlands, English, Deutsch, Français, Español, 中文).
- **Windows SmartScreen :** le fichier n'est pas signé numériquement ; à l'avertissement, choisissez *Informations complémentaires* → *Exécuter quand même*.
- **Compilation :** `dotnet build -c Release` (.NET Framework 4.8, inclus dans Windows 10/11).
